# 9. ✨ ANIMATIONS

Animation phải mượt và tinh tế.

Sử dụng:

* Framer Motion / Motion
* CSS transitions
* Intersection Observer

Animation:

### Page Load

Hero xuất hiện:

1. Avatar fade + scale
2. Name slide up
3. Description fade
4. Buttons xuất hiện
5. Background glow animate nhẹ

### Scroll

Các section:

* Fade in
* Translate Y 20–30px
* Stagger children

### Hover

Cards:

```text
translateY(-6px)
scale(1.01)
```

Không dùng animation quá mạnh.
